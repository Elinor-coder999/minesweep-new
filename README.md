# 💣 Minesweeper

**Minesweeper** is a classic logic puzzle game where the player uncovers cells in a grid without detonating any hidden mines. This version is built as a modern web app with a clean interface and responsive gameplay.

---

## 🎮 Features

- ✅ Classic Minesweeper mechanics
- 🧠 Recursive reveal of empty cells
- ⚡ Right-click to flag suspected mines
- 🔢 Timer and mine counter
